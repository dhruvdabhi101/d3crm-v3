## Notes for Claude Code

- `AGENTS.md` is the single source of truth for conventions. If you change a convention, update it there, not here.
- Before you edit, say which files you'll change. Deleting files or routes needs explicit approval.
- Verify UI changes in a real browser at 1280px and 375px against the isolated `_test` database. Never use the production database.
- Don't commit, push, or deploy unless the user asks.
